## 1. 왜 하는가, 그리고 왜 실행 전에 이 예측을 먼저 제출하는가

원고의 머리 결과(부풀림, `MT→MT − MT→L`)는 **사전 지정 검정이 실패한 뒤에 추가한 칸**에서 나왔습니다.
교수님 지적대로 제목·초록·결론 C2 가 모두 이 사후 칸에 의존하는데, **다른 곳에서 확인된 적이 없습니다.**

이를 「탐색적 발견」에서 「확인적 결과」로 올리기 위해, **NLLB 가 지원하고 MASSIVE 가 제공하는 다른 두 로캘에서
네 칸 설계 전체를 반복**합니다.

**이 예측은 실행 전에 제출합니다.** 결과가 예측과 맞든 틀리든 그대로 보고하며, 예측이 빗나간 항목은
그렇게 표시하겠습니다.

## 2. 로캘 선택과 근거 (3개 로캘)

| 로캘 | 선택 | 문자 체계 | 분절 | 기존 `ko-KR` / `zh-CN` 과의 관계 |
| --- | --- | --- | --- | --- |
| **de-DE** | ✅ 선택 | 라틴 | 공백 | 어족이 가장 멀고(게르만어족), **공백 분절 언어** |
| **vi-VN** | ✅ 선택 | 라틴 + 성조 부호 | 공백 | 어족이 멀고(남아시아어족), **공백 분절 언어** |
| **ja-JP** | ✅ 선택 | CJK | 무공백 | 한국어와 유형론적으로 가깝지만(SOV·교착·경어), **CJK 내부 일관성**을 검증할 수 있음 |

**선택 근거**: 원고의 중국어 붕괴는 **중국어에 공백이 없기 때문**입니다.
de-DE 와 i-VN 은 **둘 다 공백 분절**이므로 「효과가 분절 문제와 무관한가」를 검정하고,
ja-JP 는 **무공백 CJK** 이므로 「효과가 CJK 내부에서 일관되는가」를 검정합니다.
**공백 언어에서도 효과가 나오면 원고 결론의 적용 범위가 크게 넓어지고, ja-JP 가 ko-KR 과 같은 방향인데
de-DE/i-VN 에서 효과가 더 약하면 무공백 문자 체계 자체가 효과의 일부라는 뜻이 됩니다.**

## 3. 실행 전에 이미 아는 세 가지 (원고와 완료된 보충 분석에서 확인 가능)

1. **기제는 표면 문자열 이웃 구조입니다.** 문자 1–3 gram 코사인 ≥ 0.8 이웃 비율:
   `L 시험 → L 학습` 7.3%(한) / 6.2%(중); `MT 시험 → MT 학습` 8.5% / 7.1%;
   **`L 시험 → MT 학습` 은 0.3% / 1.8%**. 같은 출처끼리는 이웃이 있고, 출처가 엇갈리면 사라집니다.

2. **가중치를 전혀 학습하지 않는 문자열 조회로 머리 수치가 재현됩니다.**
   최근접 조회: 한 비용 −22.92, 부풀림 +11.87; 중 −13.88, +8.59.
   문자 n-gram 로지스틱 회귀: 한 −21.11, +8.00; 중 −12.19, +6.02.
   (원고 TextCNN: 한 −21.33, +11.48; 중 −13.17, +7.52)

3. **근사 중복을 빼도 효과가 유지됩니다.** 각 칸 학습셋과 코사인 ≥ 0.8 인 시험 문장을 제거한 뒤
   (한 85.5% / 중 86.7% 유지) 부풀림은 한 +11.48 → +10.83, 중 +7.52 → +6.93.

## 4. 예측

**정의**: 평가 출처 비용 = `L→MT − L→L` (음수 예상); 부풀림 = `MT→MT − MT→L` (양수 예상).
「조회 기준선」은 문자 1–3 gram 최근접 조회이며 **어떤 가중치도 학습하지 않습니다**.

### 4.1 주요 예측

| 로캘 | 분류기 | 평가 출처 비용 (예측) | 부풀림 (예측) |
| --- | --- | --- | --- |
| **de-DE** | TextCNN (문자, 시드 5) | **−8 ~ −15** | **+1 ~ +6** |
| **de-DE** | XLM-R base (시드 3) | **−4 ~ −9** | **−1 ~ +3** |
| **de-DE** | 조회 기준선 (무학습) | **−9 ~ −16** | **+2 ~ +7** |
| **vi-VN** | TextCNN (문자, 시드 5) | **−12 ~ −20** | **+3 ~ +9** |
| **vi-VN** | XLM-R base (시드 3) | **−6 ~ −12** | **+0 ~ +4** |
| **vi-VN** | 조회 기준선 (무학습) | **−13 ~ −21** | **+4 ~ +10** |

### 4.1b `ja-JP` 예측 (추가 제출)

`ja-JP` 는 **공백 없는 CJK** 로, 분절에서는 `zh-CN` 과 같은 부류이고 통사적으로는 `ko-KR` 과 같은 부류입니다(SOV, 교착어).
따라서 예측은 **두 언어 사이, 한국어에 더 가깝게** 놓입니다. 한자의 정보 밀도가 가나보다 높으므로 문자 단위 방식의 손실은 중국어보다 작아야 합니다.

| 분류기 | 기준 | L→L 예상 | 시험측 비용 | 부풀림 |
| --- | --- | --- | --- | --- |
| **TextCNN (문자)** | 79.18(한) / 78.82(중) | **77–81** | **−14 ~ −22** | **+4 ~ +10** |
| **XLM-R base** | 82.67(한) / 83.64(중) | **80–85** | **−6 ~ −11** | **+0 ~ +3** |
| **문자 n-gram 조회** | 82.91(한) / 81.21(중) | **79–84** | **−14 ~ −21** | **+5 ~ +11** |

**`ja-JP` 에 대한 세 가지 구체적 예측:**

- **P7: `ja-JP` 의 부풀림은 양수**이며 `de-DE` 와 `vi-VN` 사이에 놓입니다 — 공백 없는 CJK 라서 메커니즘상 원고의 중국어 조건에 더 가깝기 때문입니다.
- **P8: `ja-JP` 의 시험측 비용 절대값이 `de-DE` 보다 큽니다** — 공백 없는 문자 체계는 문자 단위 방식에서 손실이 더 큽니다.
- **P9 (틀릴 가능성이 더 큼): `ja-JP` 와 `ko-KR` 의 부풀림 차이가 `ja-JP` 와 `zh-CN` 의 차이보다 작습니다** — 성립하면 통사 유형(SOV 교착어)이 문자 체계보다 부풀림을 더 좌우한다는 뜻이고, **틀리면 문자 체계가 주된 원인이라는 뜻입니다.**

**주: 이 절은 `de-DE`/`vi-VN` 예측을 제출한 뒤, 그리고 `ja-JP` 를 실행하기 전에 추가로 작성했습니다.**
**작성 날짜와 최초 제출 날짜는 모두 논문 보충자료에 기재합니다.**

### 4.2 부호와 순서에 대한 예측 (틀릴 가능성이 더 큰 부분)

- **P1**: 두 로캘 모두 **평가 출처 비용이 음수** (`L→MT` < `L→L`).
- **P2**: 두 로캘 모두 **부풀림이 양수** (`MT→MT` > `MT→L`).
- **P3**: **XLM-R 의 부풀림이 TextCNN 의 부풀림보다 작음**, 두 로캘 모두.
- **P4**: **조회 기준선의 부풀림이 TextCNN 과 같은 부호·같은 크기**(차이 ±3점 이내).
- **P5**: **de-DE 의 효과가 vi-VN 보다 작음** (NLLB 의 독일어 학습 데이터가 더 많아 번역문이 현지화본에 더 가까움).

### 4.3 제가 틀릴 것으로 보는 예측

- **P6 (약함)**: XLM-R 의 부풀림이 **두 로캘 모두에서 0 과 구분되지 않음**.
  한국어 기존 결과가 +1.73 [+0.56, +2.93] 으로 **이미 0 을 제외**하므로, 이 예측은 한 로캘에서만 맞을 가능성이 큽니다.

## 5. 방법 (원고와 엄격히 일치하는 부분)

| 항목 | 설정 |
| --- | --- |
| 데이터 | MASSIVE v1.1 의 `en-US`(원문) 와 `de-DE`·`vi-VN`(현지화본) |
| 기계번역 | `facebook/nllb-200-distilled-600M`, `--splits train,test`, 원고와 동일 스크립트 |
| 고정 평가 부분집합 | 원고와 동일 규칙: 현지화 시험 문장이 현지화 학습셋에 없고, 번역 시험 문장이 번역 학습셋에 없음 |
| 모델 | TextCNN(문자, 시드 42–46), XLM-R base(서브워드, 시드 42–44), 문자 n-gram 최근접 조회 |
| 분할 | 공식 11,514 / 2,033 / 2,974 |
| 구간 | 시험 문장 부트스트랩 2,000회; 비용과 부풀림은 짝지은(paired) 부트스트랩 |
| 학습 설정 | 원고와 동일하되 **안정화 조치 유지** (선형 warmup 10%, 그래디언트 클리핑 1.0, XLM-R lr 1e-5) |

**⚠️ 설명**: 안정화 조치는 원고의 XLM-R large 에서 다수 클래스 붕괴가 나타난 뒤 추가한 것입니다.
de-DE / vi-VN 은 XLM-R **base** 를 쓰므로 같은 붕괴는 관측되지 않았지만, 일관성을 위해 같은 설정을 유지합니다.

## 6. 판독 규칙 (사후 해석을 막기 위해 미리 정함)

| 결과 | 결론 |
| --- | --- |
| P1–P4 모두 성립 | 머리 결과를 **확인적 결과로 승격**, 제목·초록·C2 의 일반화 주장 유지 |
| P2 는 성립하나 P3 또는 P4 불성립 | 일반화 주장은 유지하되 **「신경망 모델」또는 「표면 문자열 기제」안으로 한정**, 초록 수정 |
| P2 가 한 로캘에서 불성립 | **머리 결과를 탐색적 결과로 강등**, 제목·초록에서 제거하고 본문에 그대로 보고 |
| P1 불성립 (비용이 양수) | 원고의 「평가 출처 비용」방향성 주장을 다시 씀 |

**결과가 어떻든 그대로 보고하며, 저에게 불리한 항목도 포함합니다.**
